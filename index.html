The rules that let every device on the internet talk to each other.

What is TCP/IP?

TCP/IP is a set of communication rules (a protocol suite) used on the internet. IP (Internet Protocol) gets data to the right address. TCP (Transmission Control Protocol) makes sure the data arrives complete and in order.

Think of sending a parcel: IP is the address on the box, and TCP is the tracking that confirms every box arrived and was opened in the right order.

The 4 Layers

Data passes through four layers, from your app down to the cable.

4. Application

What you use: HTTP, HTTPS, DNS, FTP, SMTP

3. Transport

Splits data into segments: TCP or UDP, using port numbers

2. Internet

Adds IP addresses and finds a route: IP, ICMP

1. Network Access

Sends bits over the wire or Wi-Fi: Ethernet, MAC address

TCP vs UDP

TCP

  • Connection-based
  • Reliable, ordered delivery
  • Slower, with more overhead
  • Used for web pages, email, file transfer

UDP

  • Connectionless
  • No delivery guarantee
  • Faster, with less overhead
  • Used for video calls, gaming, streaming
